# Step 3: Rename the columns

The CSV contains:

```text
Sales
Date
Region
```

We rename them to make them easier to work with.

```python
# Rename the columns
df = df.rename(columns={
    "Sales": "sales",
    "Date": "date",
    "Region": "region"
})
```

### What happened?

Instead of writing:

```python
df["Sales"]
```

we can simply write

```python
df["sales"]
```

---

# Step 4: Convert data types

The date and sales columns need the correct data types.

```python
# Convert Sales column into numbers
df["sales"] = pd.to_numeric(df["sales"])

# Convert Date column into datetime format
df["date"] = pd.to_datetime(df["date"])
```

### What happened?

* Sales becomes a numeric value.
* Date becomes a proper date so Python can sort it correctly.

---

# Step 5: Calculate total daily sales

The dataset contains four regions.

We need **total sales per day**.

```python
# Group by date and calculate total sales
daily_sales = (
    df.groupby("date", as_index=False)["sales"]
      .sum()
      .sort_values("date")
)
```

### What happened?

Example:

Before grouping:

| Date       | Region | Sales |
| ---------- | ------ | ----: |
| 2018-02-06 | North  |  1638 |
| 2018-02-06 | South  |  1647 |
| 2018-02-06 | East   |  1731 |
| 2018-02-06 | West   |  1557 |

After grouping:

| Date       | Total Sales |
| ---------- | ----------: |
| 2018-02-06 |        6573 |

This creates one row per day.

# Step 6: Create the line chart

```python
# Create the line chart
fig = px.line(
    daily_sales,
    x="date",
    y="sales",
    title="Pink Morsel Sales Over Time",
    render_mode="svg"
)
```

### What happened?

* X-axis = Date
* Y-axis = Sales
* A line chart is generated.
* `render_mode="svg"` avoids WebGL issues.

---

# Complete Code (with comments)

```python
import pandas as pd
import plotly.express as px
from dash import Dash, html, dcc

# Read the processed CSV file
df = pd.read_csv("data/formatted_sales_data.csv")

# Rename columns
df = df.rename(columns={
    "Sales": "sales",
    "Date": "date",
    "Region": "region"
})

# Convert data types
df["sales"] = pd.to_numeric(df["sales"])
df["date"] = pd.to_datetime(df["date"])

# Group data by date and calculate total sales
daily_sales = (
    df.groupby("date", as_index=False)["sales"]
      .sum()
      .sort_values("date")
)

# Create line chart
fig = px.line(
    daily_sales,
    x="date",
    y="sales",
    title="Pink Morsel Sales Over Time",
    render_mode="svg"
)

# Add labels and styling
fig.update_layout(
    xaxis_title="Date",
    yaxis_title="Sales ($)",
    template="plotly_white"
)

# Create Dash app
app = Dash(__name__)

# Design the webpage
app.layout = html.Div([

    # Dashboard heading
    html.H1(
        "Soul Foods Sales Visualiser",
        style={"textAlign": "center"}
    ),

    # Display graph
    dcc.Graph(
        figure=fig,
        config={"displayModeBar": False}
    )

])

# Run the application
if __name__ == "__main__":
    app.run(debug=True)
```
