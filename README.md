# 📊 Price Impact Dashboard

An interactive **Python Dash** application that allows users to analyze how price changes affect sales and profitability through dynamic visualizations.

## 🚀 Features

- 📈 Interactive sales and profit visualizations
- 🌍 Region selection using a dropdown picker
- 📊 Dynamic graphs that update based on user input
- 🧪 Automated testing using Pytest and Dash Testing
- ⚙️ Bash script for Continuous Integration (CI) test automation
- 🔄 Git & GitHub version control

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Shr6/quantium-starter-repo.git
```

2. Navigate to the project

```bash
cd quantium-starter-repo
```

3. Create a virtual environment

```bash
python -m venv .venv
```

4. Activate the virtual environment

**Windows**

```bash
.venv\Scripts\activate
```

**Linux/macOS**

```bash
source .venv/bin/activate
```

5. Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Application

```bash
python app.py
```

The application will start locally and can be accessed through your browser.

---

## 🧪 Running the Tests

Run all tests with:

```bash
pytest
```

Or execute the automated CI script:

